Widget harness

A plain host page for checking the embedded widget by hand. The widget only ever runs inside someone else's page, so this is the smallest thing that reproduces that: no React, no app styles, no framework — just the <script> tag a customer pastes.

Paste a bot's public key (pk_…, from the bot's Install page) and load it. The key is remembered in localStorage so a reload keeps it. The bot must allow localhost under its widget domains.

What to check

  1. Desktop width: the panel opens bottom-right, 380px wide, and never covers the page.
  2. Narrow the window below 480px: the panel goes fullscreen — once, without flickering.
  3. Widen it again: it returns to the panel, once.
  4. Scroll this page with the panel open: the panel stays put.
  5. Console: window.ChatWidget.open(), .close(), .ask("hi").
Scroll area — the widget must stay pinned to the viewport.
